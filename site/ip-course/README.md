# 国际知识产权 · 商业情境学习课

基于用户提供的刘孔中教授《国际知识产权体系导论》93页中文课件制作的中文学习网站。

- 8个模块、46个学习单元、46道商业情境选择题；
- 首页总思维导图、知识点目录、逐点图解；
- 单选/多选提交、逐项解析、重做和本地进度；
- 93页原课件文字对照、规则来源和关键更正说明。

规则核对日：2026-09-23。商业案例为教学虚构。原课件中的历史数据、作者评价与现行法律规则已作区分。中国2026年修订布图设计条例于2026-10-15施行，学习页明确标注时间适用。

## 运行
直接用静态服务器提供本目录即可，无需构建或第三方依赖。入口为 `index.html`。
课程数据位于 `course-data.js`，交互位于 `app.js`，样式位于 `styles.css`。

GitHub Pages 使用仓库现有工作流发布 `site` 目录，本课程路径为 `/ip-course/`。

进度使用浏览器 localStorage，只保存本课程选项与判断结果，不收集身份信息或上传答题记录。
