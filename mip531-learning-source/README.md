# 知产实战研习室 · MIP531

在线学习地址：https://lingyili01.github.io/mip531-ip-learning/

四份国际和比较知识产权课件的情景学习版本。版权 10 关、商标 9 关、专利 11 关、商业秘密 10 关，每关五道多选，另有 20 道综合挑战题。

每关从业务材料开始，依次查看知识关系图、推理示例、事实变化，再作答。每道题均解释正确及错误选项；成绩页提供“问题—规则—事实—结论”应试提纲。历史与制度演变只作四条简短时间线，不考年份。

## 学习规则

- 多选必须选全且没有错选。每关 4/5 通过；通过全部 40 关后解锁综合挑战，16/20 通过。
- 同一题首次答对领取 10 金币，每关首次通过再领取 20；金币可换配色和徽章。
- 完整重做记录首次、最近、最好成绩。单题复习不修改旧测验成绩，不重复刷金币。
- 本地自动保存进行中的答题。没有账号，不会自动跨设备同步。到“记录与来源”导出文件，或复制文字备份；换设备后导入。

## 本地使用

解压离线包后打开 `site/index.html` 即可学习。浏览器对本地文件的存储支持可能不同，长期学习建议使用固定在线地址并定期备份。所有界面代码与教学内容均在包内，学习无需在线 AI。

## 文件与维护

`site/` 是可直接发布的静态网站；`content/` 是按章节编写的教学和题库文本；`course_meta.json` 存放章节、时间线、官方来源；`compile_course.py` 将文本编译成 `site/course.js`；`qa/engine.cjs` 检查判分、金币与存档规则。

维护命令：先运行 `python3 compile_course.py`，再运行 `node qa/engine.cjs`。修改后需重新检查浏览器中的题面和交互。更改题目含义或答案时，应考虑存档版本迁移，不能静默把旧答案映射成新成绩。

GitHub 发布在 `lingyiLi01/lingyili01.github.io` 的 `site/mip531-ip-learning/`。只更新该目录下本项目文件；主页、原有游戏、其他课程均保留。源码存放在 `mip531-learning-source/`，可将网站目录复制到该源码目录的 `site/` 后编译。

## 内容范围

根据用户提供的 MIP531 Session 2–5 课件重新编写。原 PPTX 未公开。每个关卡保留文件名、幻灯片页码和适用范围；官方来源集中在网页“记录与来源”。情境为教学模拟，不是学校官方题库。条约最低标准、国内规则、历史课件版本与政策建议均分开标注。

程序不包含第三方运行库、统计脚本、在线账户或支付。网站可保存和备份学习状态；它是个人练习工具，不是考试认证或防作弊系统。
